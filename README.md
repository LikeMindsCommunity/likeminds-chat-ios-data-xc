# LikeMindsChat.xcframework

A prebuilt binary of the LikeMinds Chat data layer for iOS, for teams who would rather not build it
from source.

[![License](https://img.shields.io/badge/license-Apache%202.0-blue.svg)](LICENSE)

**Docs:** https://docs.likeminds.io/

## What this is

`LikeMindsChat.xcframework`, compiled from
[likeminds-chat-ios-data](https://github.com/LikeMindsCommunity/likeminds-chat-ios-data).

Use this when you want the data layer as a binary dependency. Use the source repo if you want to
read, modify or debug it - and note the binary here can trail the source, so check the version before
assuming they match.
